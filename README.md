# ⌁ СИНАПС — блог AI-стартапа
👉 Live Demo: https://marymur-975.github.io/synapse-blog/

Полноценный многостраничный сайт-блог, собранный **вручную на чистом HTML / CSS / JS** —
без фреймворков, сборщиков и внешних зависимостей. Работает офлайн: достаточно открыть
`index.html` в браузере (или поднять статический сервер).

## 🚀 Запуск

```bash
# вариант 1 — просто открыть
open index.html            # macOS / xdg-open на Linux

# вариант 2 — локальный сервер (рекомендуется)
python3 -m http.server 8000
# → http://localhost:8000
```

## 📄 Страницы

| Файл            | Назначение                                                        |
|-----------------|-------------------------------------------------------------------|
| `index.html`    | Главная: hero-бенто, свежие материалы, рубрики, топ-5, подписка   |
| `articles.html` | Архив: полнотекстовый поиск, фильтры, избранное, сортировки      |
| `article.html`  | Статья: рендерится движком из `?id=N`, TOC, комментарии, похожие  |
| `about.html`    | О компании: история, команда, принципы, CTA                      |

## ⚙️ Движок (`assets/js/engine.js` + `assets/js/data.js`)

Весь контент живёт в `data.js` (12 статей, 6 рубрик, 4 автора) — страницы рендерятся
движком из этих данных. Что умеет движок:

- **Полнотекстовый поиск** по заголовкам, аннотациям, тегам и телу статей с подсветкой
  совпадений (`<mark>`) и хоткеем `/`;
- **Фильтры**: рубрики (чипы), теги, «только избранное»; сортировки «новые / по
  просмотрам / быстрое чтение»; параметры дублируются в URL (`?cat=`, `?q=`, `?tag=`);
- **Bento-раскладка без «сирот»**: генератор спанов всегда заполняет ряды сетки целиком;
- **Избранное** (♥) и **счётчик просмотров** — персистентно в `localStorage` с безопасным
  фолбэком в память (работает даже в sandbox-iframe без same-origin);
- **Комментарии** — локальные, хранятся в браузере читателя;
- **Страница статьи**: хлебные крошки, прогресс-бар чтения, авто-TOC с подсветкой
  активного раздела, теги, карточка автора, «читайте также» по схожести (рубрика/теги/автор);
- **Темы**: тёмная (фирменная, по умолчанию) и светлая, с запоминанием выбора;
- **UX-мелочи**: toast-уведомления, reveal-анимации по скроллу, «прожектор» на карточках,
  шаринг (Web Share API / буфер обмена), адаптив от 320 px, мобильное меню.

## 🎨 Дизайн

Современный bento-style: стеклянные поверхности, градиентные акценты
(violet → fuchsia → cyan), мягкие свечения, скругления 22 px, крупная типографика
с градиентными словами, обложки-градиенты с сеткой-паттерном. Без единой картинки —
вся графика собрана из CSS-градиентов и эмодзи, поэтому сайт полностью автономен.

## 🧪 Тесты

```bash
npm i jsdom          # один раз
node tests/smoke.test.js        # 35 проверок рендера/поиска/фильтров/тем в jsdom
node tests/screenshot.js        # визуальный QA: скриншоты всех страниц (puppeteer,
                                # нужен запущенный `python3 -m http.server 8099`)
```

Скриншоты лежат в `.screens/`.

## 🗂 Структура

```
.
├── index.html  articles.html  article.html  about.html
├── assets/
│   ├── css/style.css      # дизайн-система: токены тем, bento, компоненты
│   └── js/data.js         # контент: статьи, рубрики, авторы
│   └── js/engine.js       # движок: рендер, поиск, фильтры, тема, хранение
└── tests/                 # смоук-тесты и скриншотный QA
```

Хотите добавить статью? Допишите объект в `ARTICLES` в `assets/js/data.js` —
главная, архив, поиск и похожие подхватят её автоматически.
